# Wordel: Random Words That Speak

Welcome to **Wordel**, an engaging word-guessing game that challenges your vocabulary skills and quick thinking! In this game, you have six attempts to guess a hidden five-letter word.

## Introduction

**Wordel** is a fun and interactive word puzzle game where you need to guess a secret five-letter word. Each guess provides feedback on how close you are to the correct word, helping you refine your subsequent guesses. 

## How to Play

1. **Guess the WORDLE in six tries**: You have a maximum of six attempts to guess the hidden word.
2. **Submit Valid Words**: Each guess must be a valid five-letter word. Press the enter button to submit your guess.
3. **Color Feedback**: After each guess, the color of the tiles will change to indicate how close your guess is to the word:
   - **Green**: The letter is in the word and in the correct spot.
   - **Yellow**: The letter is in the word but in the wrong spot.
   - **Gray**: The letter is not in the word at any spot.

## Game Features

- **Interactive UI**: A simple and clean user interface that provides clear feedback on your guesses.
- **Dynamic Puzzle Generation**: A new WORDLE puzzle is generated every time you refresh the page.
- **Color-Coded Feedback**: Helps players understand their guesses with immediate visual feedback.

## Installation

To run **Wordel** locally:

1. **Clone the Repository**: 
    ```bash
    git clone https://github.com/yourusername/wordel.git
    ```
2. **Navigate to the Directory**: 
    ```bash
    cd wordel
    ```
3. **Open `index.html` in a Web Browser**: Simply open the `index.html` file with your preferred web browser.
